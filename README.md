# 英烈纪念园 · 烈士纪念资料站

一个庄重肃穆的烈士纪念资料网站。管理员在后台维护人物生平、纪念时间、照片、文献与留言，前台庄重展示；访客寄语经审核后公开；页脚版权与联系方式可在后台配置；内置内容备份与误删保护机制。

## 功能一览

### 前台（访客）
- **首页**：站点标语、纪念统计、英烈墙、最新公开寄语
- **英烈名录**：卡片式展示（肖像黑白处理），支持按姓名 / 籍贯 / 身份搜索
- **英烈详情**：生平简介、英雄事迹、纪念时间、珍贵影像、相关文献、网上祭奠（献花 🌼 / 点烛 🕯️）、寄语留言
- **文献资料**：家书、档案、报道等文献汇编，点击展开阅读
- **留言寄语**：访客提交寄语，**经管理员审核后才会公开展示**

### 后台（管理员，`/admin`）
- **人物管理**：姓名、生卒日期、籍贯、身份、**纪念时间**、生平、事迹、肖像上传
- **照片管理**：按人物上传照片、编辑说明与排序
- **文献管理**：维护文献（可关联人物），支持家书 / 档案 / 报道 / 纪念文章分类
- **留言审核**：待审核 / 已公开 / 已拒绝分栏，通过、拒绝、删除
- **站点设置**：站点名称、标语、**页脚版权、联系电话、邮箱、地址、备案号**，保存即生效
- **回收站（误删保护）**：人物 / 照片 / 文献删除后先进入回收站，可恢复或彻底删除；所有删除操作前端均有确认提示
- **数据备份**：一键创建备份（含全部数据与上传图片）、下载、从服务器备份或本地备份文件恢复、删除备份；**恢复前自动创建安全备份**；系统每天首次启动自动备份一次
- **修改密码**：管理员自助修改登录密码

## 快速开始

```bash
npm install
npm start
```

- 前台：http://localhost:3000
- 后台：http://localhost:3000/admin
- 默认管理员：`admin` / `admin123456`（**首次登录后请立即在「修改密码」中更换**）

## 技术说明

- **后端**：Node.js + Express，接口分为公开接口（`/api/*`）与管理接口（`/api/admin/*`）
- **数据库**：SQLite（经 sql.js WASM 运行，免原生编译），数据文件持久化在 `data/memorial.db`
- **鉴权**：scrypt 密码哈希 + HttpOnly Cookie 会话（12 小时滑动过期）
- **上传**：multer，仅接受图片、单文件不超过 5MB，存放于 `public/uploads/`
- **备份**：`backups/backup-时间戳/` 内含 `data.json`（全量数据）与 `uploads/`（图片副本）

## 误删与备份机制

| 机制 | 说明 |
| --- | --- |
| 删除确认 | 后台所有删除操作均弹出确认框 |
| 软删除 | 人物 / 照片 / 文献删除后进入回收站，前台立即不可见 |
| 回收站 | 可一键恢复；彻底删除需二次确认 |
| 手动备份 | 后台「数据备份」随时创建，可下载到本地 |
| 自动备份 | 每天首次启动自动备份；恢复操作前自动再备份当前数据 |
| 恢复 | 支持从服务器备份或上传的备份 JSON 文件恢复 |

## 目录结构

```
├── server.js            # 服务入口
├── db.js                # 数据层（sql.js 封装、建表、示例数据）
├── lib/
│   ├── auth.js          # 密码哈希与会话
│   └── backup.js        # 备份 / 恢复
├── routes/
│   ├── public.js        # 前台公开接口
│   └── admin.js         # 后台管理接口
├── public/              # 前台页面与静态资源
│   ├── index.html       # 首页
│   ├── martyrs.html     # 英烈名录
│   ├── martyr.html      # 英烈详情
│   ├── documents.html   # 文献资料
│   ├── messages.html    # 留言寄语
│   └── admin/           # 管理后台
├── data/                # 运行时数据库（已 gitignore）
└── backups/             # 备份文件（已 gitignore）
```

## 注意事项

- 首次启动会自动创建示例数据（3 位示例人物、文献与寄语），可在后台修改或删除后录入真实资料
- 管理员会话保存在内存中，重启服务后需重新登录
- 生产部署建议置于 Nginx 等反向代理之后并启用 HTTPS
